Privacy Policy

Household E-mail Agent · Last updated 16 November 2026

Summary

Household E-mail Agent is a private, single-user tool. It accesses one Gmail mailbox — the mailbox of the person who installed and authorized it — and it runs on that person's own hardware. It has no other users. It does not sell, share, transfer, or monetize any data, and it does not use any data for advertising or for training artificial-intelligence models.

Who operates this application

This application is operated by a single private individual for their own personal use. It is not a business, not a service offered to the public, and has no customers.

What data is accessed

When the owner grants access through Google's standard OAuth consent screen, the application can access the following from the owner's own Google Account:

  • The content, headers, attachments, and labels of messages in the owner's Gmail mailbox
  • The ability to compose, send, modify, label, and file messages in that mailbox
  • The basic profile information Google provides to identify the account

The exact permissions requested are always shown on the Google consent screen before access is granted, and can be reviewed at any time in the owner's Google Account security settings.

How that data is used

Data is used solely to carry out tasks the owner has asked the application to perform on their own mailbox: reading and summarizing mail, sorting and labeling it, drafting and sending replies, and flagging items that need attention. It is used for no other purpose.

Where data is stored

The application runs on hardware owned and controlled by the owner, on the owner's own private network. Message data is processed there. Nothing is stored on any third-party server operated by this application, because there is no such server. Any local copies, caches, or logs exist only on the owner's own machine and are under the owner's direct control.

Data sharing

No Google user data is sold, rented, traded, or shared with any third party. Data is not transferred to anyone for advertising, market research, credit assessment, or lending purposes. Data is not used to develop, improve, or train generalized artificial-intelligence or machine-learning models.

Where the application relies on an external service to carry out a task the owner has requested, only the minimum content needed for that task is transmitted, and only to complete that specific request on the owner's behalf.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

The application retains no data beyond what is necessary to perform the owner's requested tasks. Any locally held data can be deleted by the owner at any time by removing it from their own machine. Revoking the application's access, as described below, ends all further access immediately.

Revoking access

The owner can revoke this application's access at any time from the Third-party apps & services page of their Google Account. Revocation takes effect immediately and permanently invalidates all existing tokens.

Children

This application is not directed at children and is not made available to anyone other than its single owner.

Changes to this policy

If this policy changes, the revised version will be posted at this same address with an updated date.

Contact

Questions about this policy can be sent to the support address listed on the Google consent screen for this application.
